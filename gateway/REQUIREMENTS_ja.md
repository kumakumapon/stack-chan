# 日本語会話 Gateway の要件

対象: M5StackChan CoreS3 1台 / Windows 11 / Ryzen AI 9 / メモリ32GB / RTX 5060 8GB。

## 合意した機能

- Codex CLI、Claude Code、Lemonade、LM Studio をブラウザ管理画面から切り替える。
- CLI は利用者がログイン済みの公式CLIを起動し、サブスク認証をCLIに任せる。
- 音声認識・音声合成は無料のローカル処理。モデル等の初回導入だけネット接続を使う。
- 日本語で雑談し、返答に合った表情・うなずき・視線を既存の身体ツールで実行する。
- 顔タップまたは管理画面で開始・停止。開始中は発話を自動検出する。
- 返答中はマイクを止める。顔タップまたは管理画面で返答を中断する。
- PC内に会話履歴を保存し、再起動とLLM切替後も直近の会話を引き継ぐ。画面から削除できる。
- 名前・性格を画面から変更できる。
- ダブルクリックでGatewayと管理画面を起動する。

## 実装上の既定値

- 管理画面はPC本人用の `127.0.0.1:8766`、本体接続はLAN用の `:8765`。
- 音声認識: faster-whisper small / 日本語固定 / CPU int8。GPUのVRAMをLLMに残す。
- 音声合成: ローカルVOICEVOX。インストール済みエンジン/アプリを利用し、話者を選択できる。
- 会話履歴は本体IDごとに最大1000往復、LLMへの文脈は直近12往復。
- 返答は最大600文字。CLI/LLM待ちは120秒まで。失敗・利用上限・未接続は画面に表示する。
- 切替・履歴削除時は進行中の返答を中断する。自動で別の有料サービスへ切り替えない。
- 初版では外部MCP、PC操作、ファイル操作、歌・踊り、長期の人物記憶は追加しない。

## 完成確認

1. 設定の保存・再起動後の復元と、4プロバイダーの切替ができる。
2. ローカル音声認識とVOICEVOXの音声を既存PCM経路で送れる。
3. 本体の操作確認を待って開始・停止・中断・テキスト送信を行う。
4. 会話履歴が保存され、プロバイダーを変えても文脈を渡せる。削除後は渡さない。
5. 不正なLLM出力・外部入力は任意の身体操作やシェル実行にならない。
6. Nodeの振る舞いテスト、型検査、lint、関連ファームウェアテストを通す。
7. 実機の日本語認識、再生、顔タップ、サーボと4サービスへの実接続は、実行した結果と未確認を分けて記録する。
