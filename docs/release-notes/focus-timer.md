# 集中タイマー（Issue #54）

Release impact: **minor**

標準ホストに、オフラインで使える「集中タイマー」Mini Appを追加しました。
集中5・15・25分、休憩5分、開始・一時停止・再開・中止に対応し、画面を閉じても計時が続きます。
完了は画面とアプリ一覧に保持され、次の集中や休憩は手動で開始します。
会話や別アプリを上書きする通知や、タイマーによる音声・サーボ・LEDの演出はありません。

計時中はCompanionの自発的待機リアクションだけを一時的に抑制し、永続設定は変更しません。
Virtual Petと共存し、Petの保存データやXPには影響しません。
再起動時に実行中・一時停止中だったセッションは中断として扱い、電源OFF中の経過は推測しません。
Simulatorの非表示時は一時停止し、復帰後は手動で再開します。
保存失敗と中断理由は文字で表示し、日本語・英語・中国語に対応します。

利用手順・実機検証項目: [集中タイマー](../../firmware/docs/focus-timer_ja.md)。
実機の25分計時精度や、背景ブラウザでの確実な通知は未保証です。
