# 生活クエスト・3問クイズ

Issue [#59](https://github.com/kumakumapon/stack-chan/issues/59) の②③を標準ホストのMini Appとして追加しました。追加MOD・ネット接続・AI契約は不要です。顔をタップしてメニューを開き、Mini App一覧から「生活クエスト」「3問クイズ」を選びます。一覧が画面に収まらない場合は上下にスワイプできます。

## 生活クエスト

- 「机を片付ける」「本を読む」「明日の準備」の3件です。タップでチェックし、もう一度タップすると取り消せます。
- 全完了の祝福は1回のチェックリストにつき一度だけです。取り消し・再完了・再起動では繰り返しません。
- 「次の回を始める」で確認してからチェックを消します。日付や集中タイマーの満了による自動リセット・自動完了はありません。
- チェックと祝福済みフラグは変更時だけ保存します。保存に失敗した場合は画面下部をタップして再試行できます。保存成功前に電源を切ると変更を失う場合があります。

## 3問クイズ

- 1回3問、各問3択です。回答後は正解と短い解説を表示し、「次の問題」で進みます。連打で二重採点しません。
- 同梱6問は、足し算、バイトとビット、分と秒、三角形、1週間、2進数です。正答表はそれぞれ `5 / 8 / 60 / 3 / 7 / 2` です。
- 間違えた問題は回答時に保存され、次の回で優先出題します。正解すると復習対象から外れます。それ以外の問題は順に巡回し、同じ回に重複出題しません。
- 途中終了するとその回のスコアは破棄しますが、回答済みの復習対象は保持します。出題中の問題や経過時間は保存しません。
- 独自JSONの取り込み、教材編集、Anki連携、間隔反復は今回のMVPには含みません。問題モデルは3〜32問・本文80文字・解説120文字・選択肢2〜3個/各36文字以内を検証します。

## 共存と保存

保存形式はどちらもversion 1です。`stackchan_quest/state` と `stackchan_quiz/state` に分離し、Petと集中タイマーの領域を使用しません。破損・未対応バージョンのデータは初期状態で開き、保存エラーを表示します。

今回の祝福と正解反応は画面表示です。サーボ・音声・会話セッションを起動せず、ゲーム用 `reportResult` やPet XPは付与しません。表示中はCompanionの待機動作を抑制し、戻る・登録解除時に解放します。タイマーやイベント購読を作らないため、終了後に演出が遅れて実行されることはありません。

## 検証手順

自動確認は `firmware/` で実行します。

```sh
npm run test:unit
npm run check:architecture
STACKCHAN_MODULE_TEST_FILTER=daily-mini-apps npm run test:moddable
```

最後のコマンドはModdable SDKとLinux Piu Simulatorが必要です。状態復元・保存失敗からの再試行・完了解除・3問の採点・復習・終了・別Mini Appとの共存を確認します。

WASMとPet MODのビルド・Galleryへの配置、Webのビルド後に `web/` から `node simulator/daily-mini-apps-test.mjs` を実行すると、実際のLCD入力経路で保存・再読み込み・復習・Pet併用・一覧ドラッグを検証します。

CoreS3実機とWASMブラウザでは次を確認し、結果を別々に記録してください。ビルド・Linux Piu試験の成功だけで実機/WASM確認済みとはしません。

- [ ] 日本語/英語/中国語の本文・解説・ボタンが欠けず、下端の保存再試行をタップできる。
- [ ] クエストを1件チェック→戻る→再起動して保持される。
- [ ] 全完了→取消→再完了で最初の祝福を繰り返さない。次の回の確認取消でチェックが消えない。
- [ ] クイズを誤答→電源再投入し、次回最初に同じ問題が出る。正解すると復習対象から外れる。
- [ ] 回答ボタンを連打しても次の問題を勝手に回答しない。3問で結果が出る。
- [ ] 戻る・再表示を10回繰り返して、待機動作が復帰する。
- [ ] Pet MODと集中タイマーがある状態で一覧をドラッグし、最下行を起動できる。ドラッグだけで途中のアプリが開かない。
- [ ] 集中タイマーを走らせてクエスト/クイズを使い、時間・Pet状態が変にリセットされない。
