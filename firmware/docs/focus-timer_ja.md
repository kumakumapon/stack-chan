# 集中タイマー

標準ホストのアプリ一覧から使える、オフラインの集中・休憩タイマーです。
PC、Gateway、クラウド設定や追加機材は必要ありません。Wi-Fiなしの場合は起動時に「オフライン」を選びます。
標準UIを使うVirtual Pet MODでも、MODを入れ替えずに同じタイマーを使えます。

## 操作

1. 顔をタップし、AppBarのアプリ一覧から「集中タイマー」を開きます。
2. 集中5・15・25分、または休憩5分を選び、「開始」を押します。
3. 「一時停止」「再開」「中止」を使えます。AppBarの「戻る」は画面だけを閉じ、計時は続きます。
4. 満了は「集中 / おわり」「休憩 / おわり」として保持され、アプリ一覧にも状態が出ます。
5. 「もう一度」「5分休憩」「終了」を選びます。次のタイマーは必ず手動で開始します。

中止や一時停止に失敗判定・減点はありません。完了しても会話、別アプリ、音声、演技の画面や動作を奪いません。
タイマー自身は音声・サーボ・LEDを動かさず、マイク・カメラも使いません。
計時中はCompanionの自発的な待機リアクションだけを抑え、瞬きとユーザーが始めた操作は続きます。
設定の `companion.idleReactions` は書き換えません。Petなど任意MODが独自に行う動作は抑制しません。
タイマー満了による `taskCompleted` やゲーム結果は発行せず、PetのXPを付与しません。

## 保存と中断

前回の設定と単一セッションの状態を、状態変更時だけ `stackchan_focus/state` に保存します。
毎秒の書き込み、作業内容、日別履歴はありません。Petの `stackchan_pet/state` とは別の領域です。

- 実行中・一時停止中に再起動すると「中断」を表示します。前回と同じ設定で最初から開始するか、終了を選べます。
- 電源OFF中の経過や、中断時の正確な残り時間は推測しません。
- 完了状態は確認待ちとして復元されます。自動で休憩を始めたり、完了演出を再生したりしません。
- 保存が失敗すると画面とアプリ一覧に表示します。計時は続けられますが、再起動時の復元は保証できません。次の状態変更で保存を再試行します。
- 時計が逆行・不正値になる場合も「中断」とし、最初から開始できます。

Simulatorのブラウザ保存キーは `stackchan.focus.state.v1` です。
タブが非表示になると一時停止し、戻った後は「再開」を押して続けます。
ブラウザが終了・凍結して保存できなかった場合、再読込時は「中断」になります。
背景タブでの継続計時や確実な通知、アラーム時計用途は保証しません。

## 開発・検証

ホストが `main.ts` で登録し、MODの `onContextCreated` に依存しません。
Mini Appのdisposeは画面購読だけを解除します。ホストcloseはTimer、登録、購読、Companion抑制を解除します。
contextを作らないMODや、ホストUIを全面置換するMODは対象外です。

純粋なモデル、注入可能な時計・スケジューラ・保存を持つサービス、Piuの表示を分離しています。
CoreS3は `Time.ticks`、WASMはブラウザの単調増加時計で期限を評価し、カレンダー時刻は使いません。
通常のコールバック遅延では期限から再計算し、中止・再開始前の世代のコールバックは無視します。

ファームウェアディレクトリで実行します。

```sh
npm test
npm run check:architecture
npm run test:moddable -- host/app/__tests__/focus-timer
npm run build:wasm
npm run mod:build:simulator
node ../web/mod-gallery/stage-pet.mjs
npm --prefix ../web run build
cd ../web
node simulator/focus-timer-test.mjs
```

WASM E2EはPlaywrightの時計を進め、実際のLCD入力から操作します。製品UIに短縮プリセットは追加しません。
日本語k8x12と中国語CJKフォントの表示文字をarchitectureチェックで検証します。

### CoreS3実機での確認記録

Simulatorや自動テストだけで実機の精度・操作性を達成済みとは扱いません。
対象FWコミット、機種、操作、外部時計との差・表示遅延と結果をリリースPRへ記録してください。

- オフラインで集中25分→手動で休憩5分。25分の暫定目標は外部時計との差2秒以内。
- 顔／別アプリへの往復、タッチ連打、一時停止・再開・中止、電源断・再起動。
- タイマーによる音声・サーボ・LED駆動がないこと、明示的な会話・撫でる操作の継続。
- AppBarの戻る・会話／録音表示、320×196のレイアウト、日本語フォントと操作性。

この環境ではCoreS3実機に接続していないため、実時間計測と実機操作は未検証です。
