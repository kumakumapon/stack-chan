# 暮らし工房

Mini Appランチャーの「暮らし工房」から、おはなし・通知と伝言箱・任意演出の設定を開けます。日英中の表示に対応します。①まねっこ記憶ゲーム、②生活クエスト、③3問クイズの基本操作は従来どおりです。

## 演出とPet

「工房の設定」の仕草・短いお知らせ音・Petとの達成共有・通知受信は初期状態でOFFです。クエスト全完了、クイズ1回完了、記憶ゲームの結果で短い音やPetへの活動イベントを使えます。記憶ゲームの動きはゲーム内のスイッチで選択します。クエスト・クイズの成功演出とおはなしの演出は工房の仕草設定に従います。

Pet MODを使用中の場合だけ活動を受け取ります。XPは1回2、10秒のクールダウンがあり、連番をPetの保存データとともに記録します。クエストの取り消し・再完了では再報酬を出しません。終了時に、その画面が始めた演出をキャンセルします。短い音は最大80msで、読み上げではありません。

## 自分のクイズ教材

Web Simulatorの「暮らし工房 → クイズ教材を作る」で教材名、問題、選択肢、正解、解説を編集できます。「教材を保存」でJSONを書き出し、ファイルから再編集できます。

- Simulator: 「Simulatorに取り込む」の成功表示後、クイズを開き直します。ブラウザのlocalStorageに教材と復習履歴を保存します。
- 本体: 本体をBLE設定モードにし、Web Bluetooth対応ブラウザで「本体に取り込む」を選びます。成功表示後、本体の設定画面を終了（再起動）してクイズを開きます。
- 取り込みに失敗・切断した場合、直前の教材は維持されます。NVSは900文字以下の分割データを二つの領域に交互保存し、最後に参照先を切り替えます。
- 教材のIDまたは内容が変わった場合、前の教材の復習履歴は新教材へ引き継ぎません。取り込み中のラウンドは開始時の教材を使います。

形式は `version: 1`、`id`（小文字英数字・ハイフン、32文字以内）、`title`（32文字以内）、`questions`（3〜32問）。各問に `id`、`prompt`（80文字以内）、`choices`（2〜3個、各36文字以内）、`answer`（0始まり）、`explanation`（120文字以内）を指定します。JSON全体は20,000文字以内です。画面に収まるよう全角文字は2文字幅として、問題文は46幅×2行、解説は46幅×5行、選択肢は1行40幅以内にも制限します。

```json
{"version":1,"id":"math","title":"足し算","questions":[
  {"id":"one","prompt":"1+1は？","choices":["2","3"],"answer":0,"explanation":"1と1で2です。"},
  {"id":"two","prompt":"2+2は？","choices":["3","4"],"answer":1,"explanation":"2と2で4です。"},
  {"id":"three","prompt":"3+3は？","choices":["6","7"],"answer":0,"explanation":"3と3で6です。"}
]}
```

本体のフォント収録範囲にない絵文字・文字は表示できません。日本語・英数字・同梱UIの中国語文字を推奨します。Anki同期・本格的な間隔反復は含みません。

## おはなし

同梱のオリジナル台本は5場面、最大2択、2結末です。文字とタッチだけで完結します。「最初から読む」で先頭へ、AppBarの戻るで終了できます。終了した画面の古いタップは無効です。台本の検証器は存在しない参照、到達不能な場面、ループを拒否します。自由生成やユーザー台本の取り込みは対象外です。

## 仕草ミニスタジオ

Web Simulatorで名前付き動作・Reaction、開始時刻、全体の長さを編集し、再生・停止・ローカル保存・再読込・JSON入出力を行えます。Mini Appや会話を閉じてからプレビューしてください。

作品は0.5〜30秒、1〜32cue、開始時刻は昇順で最低500ms間隔です。さらに既存Performanceの各動作の長さ・重なり制限を適用します。短すぎる間隔は再生時にも拒否します。停止やSimulator再起動時に古いcueを破棄します。自由なサーボ角度、音声、スクリプト実行、本体への作品取り込みは含みません。

## 通知・伝言

[Gatewayの手順](../../gateway/INBOX_ja.md)を参照してください。工房の受信設定をONにした時だけ5秒間隔で取得します。会話・Agentセッション・常時マイクは開始しません。会話中、他のMini App、音声・演出の使用中は通知の仕草を保留します。初回取得の既存通知は静かに表示し、再接続の未読通知は最大1回の仕草にまとめます。通知がユーザーの画面を閉じることはありません。

## 容量

手のマスクは同じ画像・セル配置をRLE4に変換し、両手で154,896→94,354バイト（60,542バイト削減）。従来の1bit変換と同じalpha閾値128で二値化してからRLE4に格納するため、輪郭は従来と同じです。factory/MOD/NVSのパーティション構成と全機種の3言語を維持します。

release CIのsummaryと `firmware-size-<target>` artifactに、binary容量・factory上限・残量・上位リソースを掲載します。ローカルではreleaseビルド後に `node scripts/report-firmware-size.mjs <target>` をfirmwareディレクトリから実行できます。容量超過は引き続きビルド失敗です。追加機能後の実測値はPRのCI結果を参照してください。

実機でのタッチ、BLE教材送信、NVS電断耐性、首の可動範囲、Petとの併用は #63 で確認を追跡します。Simulator検証は実機成功を意味しません。
