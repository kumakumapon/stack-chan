# まねっこ記憶ゲーム

標準ホストに組み込まれた、オフラインの順番記憶ゲームです。
本体のアプリ一覧から「メモリー」（英語・中国語では `MEMORY`）を開きます。
MODの追加、PCの常駐、Wi-Fi、音声認識、AI契約は必要ありません。

## 遊び方

1. 「開始」をタップします。
2. `1 / 2 / 3` のどれが光るか、順番を覚えます。
3. 「同じものをタップ」と表示されたら、同じ順番で押します。
4. 正解したら「次」を押します。前の順番に一手追加されます。
5. 12回正解すると終了です。間違えた時は、その時点で押すべき記号を赤く表示します。

今回のスコアは最後まで正解したラウンド数です。途中で閉じると終了し、再度開くと最初から遊べます。
ランキングや保存データは作りません。色が区別しにくくても、番号・文字と点灯位置で判別できます。

## 任意の身体表現

初期状態は「動きOFF」です。画面の番号だけで全ラウンドを遊べます。音は鳴らしません。
「動きON」では、お手本に既存の `yes / no / greeting` を、判定に `success / failure` を対応させます。
通常の顔はMini Appの下に隠れるので、お手本の主表示はLCDの番号です。
首などの身体演出は強度0.3の補助表示であり、機種によって見え方は異なります。

会話・音声・Performance・別のReactionが使われている時は、演出を省略してゲームを続けます。
終了や「動きOFF」は、ゲームが開始したReactionだけをキャンセルします。
後から別の操作が同じReaction名を再生していても、それを停止しません。
キャンセルは予約された演出を止めて元の姿勢へ戻すため、サーボの物理的な瞬時停止ではありません。

## 既存機能との関係

- Hostが登録するMini Appなので、Virtual Pet MODを入れたまま使えます。
- 集中タイマーはバックグラウンドで継続します。
- PetのXP・保存データには変更を加えません。ゲーム結果はMini Appの既存イベントへ一度だけ通知しますが、Pet側の報酬対象への追加は含めません。
- AppBarの「戻る」、別アプリへの切り替え、登録解除で出題Timer・購読・自分のReactionを解放します。
- 起動のたびに動きOFFへ戻ります。放置時も自動で次ラウンドを始めません。
- ブラウザ非表示時のTimer遅延では進行が遅くなることがあります。復帰時に全記号を一気に提示せず、表示と空白の区間を順に進めます。やり直したい時は「戻る」で閉じて開き直します。

## 実装と検証

- `host/app/memory-game.ts`: 出題、入力ロック、採点、上限、タイマー所有。
- `host/app/memory-game-mini-app.ts`: Piu表示とタッチ入力。
- `host/app/memory-game-host.ts`: Host登録、アイドル制御、任意のReaction。
- `reaction.playOwned(name, options)`: 空いている時だけ再生し、成功時にその再生だけをキャンセルするハンドルを返します。旧ホストでは省略可能なAPIです。

検証コマンドは `firmware/` から `npm run test`、`npm run test:moddable`、`npm run build:wasm`。
WASMとPet MODの準備後、`web/` から `node simulator/memory-game-test.mjs` でLCD操作を確認します。

実機受け入れ確認はM5StackChan CoreS3で別途行います。

- [ ] オフラインで開始→正解→次ラウンド→誤答→再挑戦を操作できる。
- [ ] LCDの表示が欠けず、「戻る」が常に使える。
- [ ] 動きOFFで音声・首・LEDの演出が発生しない。
- [ ] 動きONの可動範囲と復元動作を確認する。
- [ ] 出題中・判定中の終了で次の動作が始まらず、Petや会話の後続動作を誤って停止しない。
- [ ] Petと集中タイマーを併用して操作できる。

自動テストやビルドの成功は、物理サーボ・タッチパネルの実機検証とは区別してください。
