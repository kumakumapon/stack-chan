# WebブラウザーでM5StackChan CoreS3を設定する

[English](./setting-preferences-web.md)

対応実機はM5StackChan CoreS3のみです。Web Bluetooth対応のChromeなどを使います。
BLEで接続するため、本体のWi-Fiが未設定でも設定できます。

## 接続と保存

1. 本体の起動時に画面へ触れ、起動画面の「設定」を押して本体設定画面を開きます。
2. [Web設定画面](https://kumakumapon.github.io/stack-chan/develop/web/preference/)を開き、「BLEで接続」から`STK`を選びます。
3. 接続済みになったら本体から読み出した値を確認して編集し、「設定を保存」を押します。変更した項目だけを送ります。
4. 保存後は本体を再起動します。言語・タイムゾーン・音量は本体の設定画面にもすぐ反映されます。

送信中は編集を無効にします。切断後はフォームを初期状態へ戻すため、再接続して本体の値を読み直してください。
「Wi-Fi設定を消去」は確認後にSSIDとパスワードを空にし、次回起動をオフラインにします。

## 設定項目

| グループ | 内容 |
| --- | --- |
| Wi-Fi | SSID、パスワード、保存済み接続情報の消去 |
| 外観 | シンプル・いぬ・画像・小さい顔、本体の日本語・英語表示 |
| 時刻 | 本体と共通の17都市のタイムゾーン。時計・おやすみ時間帯に使用 |
| 音声合成 | サービス、音量、および選択したサービスが使用する項目 |
| 会話 | オフ・Gateway・USB、起動時の接続。Gatewayのときだけ接続先・ID・トークン・マイク設定を表示 |
| Companion | 起動時の挨拶、待機反応、低電池通知、おやすみ時間帯と開始・終了時刻 |
| MOD向けの設定 | 対応AI MODのAPIキー・音声認識ホスト、MCP Server用のBearerトークン。必要時に展開 |

タイムゾーンは固定UTCオフセットです。夏時間は自動切替しません。
音量は0～1の範囲を0.01（1%）単位で指定します。
おやすみ時間帯は30分刻みの候補に加え、本体に保存されている分単位の値も表示します。

### 音声サービスごとの項目

| サービス | 音量以外に表示する項目 |
| --- | --- |
| stackchan-voice | 標準／かわいい音声、話速（標準100、整数） |
| VOICEVOX | ホスト、ポート、話者ID |
| VOICEVOX Web（tts.quest） | サービストークン、話者ID |
| リモートWAV | ホスト、ポート |
| ElevenLabs | サービストークン、音声ID、モデル |
| OpenAI | サービストークン、音声ID、モデル、話速（標準1）、対応モデル向けの音声指示 |
| ローカル音源 | 追加項目なし |

サービスを切り替えると、サービス固有の音声・話速・モデルなどを初期値に戻し、
以前のサービスのトークンを空にします。本体への反映は「設定を保存」を押したときです。
保存前に接続先と認証情報を確認してください。

AI MOD用のトークンは対応MODが読み出す値です。Gateway会話のAI APIキーやシステム指示はGateway側で設定します。
一部のAI MODの音声認識ホストは音声合成のホストと共通です。

## 整理した旧項目

旧ドライバー選択、パン・チルト補正、汎用サーボ通信速度、未実装のGoogle TTS候補、
参照先のなかったAIシステムロールは設定対象から外しました。
専用サーボのUART・ゼロ位置・可動域・電源設定はM5StackChan CoreS3の実装で管理します。
既存の保存領域を一括消去する変更は行いません。

## 検証範囲

`web/preference-contract.test.mjs`でWebと本体の設定キーを照合します。
ブラウザー検証ではUART/GATTの模擬本体を使い、実際のWeb画面・BLEクライアントによる
読出し、変更分の保存、再接続、サービス別表示、1%単位の音量操作、画面幅を確認します。
この検証はCIのpagesスイートに含まれます。

WASMシミュレーターの`PreferenceServer`はBLE無線を持たないスタブです。
WASMの起動・既存機能の回帰検証と、模擬本体によるWeb設定の検証を区別します。
実機BLEの往復、各音声サービスの実接続・発話、時刻・おやすみの実機動作は別途確認が必要です。
